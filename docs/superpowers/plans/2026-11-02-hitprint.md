# Hitprint Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Production note:** Tasks 1–8 are built **on camera** by Claude Code in VS Code on the user's Mac. Each chapter is one recorded prompt that points Claude Code at this file. The off-camera reviewer checks each chapter before the next one is recorded.

**Goal:** A local, open-source CLI plus agent skill that finds a creator's personal "hitprint": the measurable traits their best short videos share. It works from a YouTube handle or from a folder plus exported stats.

**Architecture:** A pure-Python package (standard library only) with one module per stage: collect → fetch → measure → analyze → report. It shells out to `yt-dlp`, `ffmpeg`/`ffprobe` and `whisper`. A `SKILL.md` lets Claude Code, Codex and other agents drive the CLI.

**Tech Stack:** Python 3.11+, pytest, ffmpeg/ffprobe, yt-dlp, openai-whisper CLI (optional).

**Spec:** `docs/superpowers/specs/2026-11-02-hitprint-design.md`

## Global Constraints
- **Name:** Hitprint. **Command:** `hitprint`. **Outputs:** `hitprint-report.html`, `my-formula.md`, `hitprint-data.json`.
- **Dependencies:** standard library only. The outside tools are ffmpeg, ffprobe, yt-dlp and whisper. Whisper is optional: without it the first-word check is skipped and the report says so.
- **Rule thresholds:** a rule is reported only when **each group has ≥ 5 videos** and the **median ratio is ≥ 1.3×**. The minimum is **10 usable videos**.
- **Skipped videos:** anything younger than **3 days** (by upload date).
- **YouTube:** public data only, no login by default, with an optional `--cookies-from-browser BROWSER`. Downloads are 360p, cached, and spaced **≥ 2 s** apart. A bot check gets **3 retries** with backoff.
- **Wording rules:**
  - Every rule shows its sample size ("based on 14 vs 12 videos").
  - The report carries the line "Patterns from your own videos, not proof."
  - Never claim causation.
- **Privacy:** everything runs locally. Nothing is uploaded.
- **License and install:** MIT. Install with `npx skills add SOULGPT/hitprint`, but only after the user approves publishing.

## Review Focus
1. **A channel with fewer than 10 usable Shorts** should exit with "Hitprint needs at least 10 videos (found N)", with no stack trace. Tested in Task 6.
2. **A bot check or 429 halfway through the downloads** should retry 3 times, then carry on with the videos already fetched. Failed videos are listed in the report. Tested in Task 4.
3. **A video with no speech:** `first_word_s` is `None`, it is left out of that one rule's groups, and it is never counted as 0. Tested in Tasks 2 and 3.
4. **A stats file with unfamiliar headers or number formats** ("1.2K", "1,234", "12%") should parse correctly. Unknown columns are ignored. Tested in Task 7.
5. **A feature where every video has the same value**, or one group is empty, is skipped with no divide-by-zero. Tested in Task 3.

### Task 3: analyze — find the creator's rules
**Files:**
- Create: `hitprint/analyze.py`
- Test: `tests/test_analyze.py`

**Interfaces:**
- Consumes: `Video`, `Rule`.
- Produces: `find_rules(videos: list[Video], score: str = "views", min_group: int = 5, min_ratio: float = 1.3, seed: int = 7) -> list[Rule]`, sorted by `log(ratio) * confidence`, descending.

**Splits:**
- **Numeric features use fixed thresholds:**
  - `first_cut_s < 1.0`
  - `first_word_s < 0.5`
  - `longest_shot_s < 4.0`
  - `cuts_per_10s ≥ 3`
  - `duration_s < 25`
  - `title_len < 45`
  - `first_frame_brightness ≥ 80`
  - `loop_diff < 20`
  - `lufs` between -16 and -12
- **Booleans** split on true/false.
- **`series_prefix`** splits on "the most common prefix shared by ≥ 3 videos" vs. the rest.
- **Upload hour** splits at the creator's median hour.
- **Upload weekday** splits weekend vs. weekday.

**Confidence:** the share of **1,000 bootstrap resamples** (seeded) in which the better group's median stays above the worse group's.

**`text`:** plain English, e.g. "Shorts where the first cut comes before 1s get 2.1× the views (based on 9 vs 14 videos)". **`fixable`** is False for series. It is True for upload hour and weekday, because the creator can choose when to post.

- [ ] **Step 1: Failing tests**
  - `test_rule_found`: 6 videos with `first_cut_s=0.5`, views 1000; 6 with `first_cut_s=3`, views 300. One rule, ratio ≈ 3.33, "6 vs 6" in the text.
  - `test_min_group`: 4 vs 8 gives no rule.
  - `test_min_ratio`: ratio 1.2 gives no rule.
  - `test_none_excluded`: `first_word_s=None` videos are excluded from that feature's groups only.
  - `test_constant_feature_skipped`: every value identical gives no rule and no exception.
  - `test_score_stayed`: with `score="stayed_pct"`, `stayed_pct` is used.
- [ ] **Step 2: Run them.** Expect FAIL.
- [ ] **Step 3: Implement** using `statistics.median` and `random.Random(seed)`.
- [ ] **Step 4: Run them.** Expect PASS.
- [ ] **Step 5: Commit** `feat: rule finder with sample-size and ratio thresholds`

### Task 5: report — HTML, my-formula.md, JSON
**Files:**
- Create: `hitprint/report.py`, `hitprint/report_template.html` (inline CSS, dark style like Shorts Doctor)
- Test: `tests/test_report.py`

**Interfaces:**
- Consumes: `Video`, `Rule`.
- Produces: `write_outputs(videos: list[Video], rules: list[Rule], out_dir: Path, meta: dict) -> dict[str, Path]`, keyed `report`, `formula`, `data`.

**HTML sections, in order:**
1. Header: handle or folder, video count, date.
2. **Your hitprint:** the top 5 rules.
3. **Your next 3 fixes:** the top 3 rules where `fixable` is true, each phrased as an action.
4. **Best vs worst:** first-second filmstrips (4 frames, 0–1s) of the top 3 and bottom 3 by score, embedded as base64 JPEG.
5. Every video, as a table.
6. Skipped and failed videos, with reasons.
7. Footer: "Patterns from your own videos, not proof."

When there are no rules, sections 2 and 3 are replaced by "No clear patterns yet — keep posting and run Hitprint again after 10 more videos."

**`my-formula.md`:** the rules written as bullet instructions for an AI scriptwriter, plus the sample sizes.

### Task 7: Any-platform folder mode *(video chapter 3)*
**Files:**
- Create: `hitprint/stats.py`, `templates/stats-template.csv`
- Test: `tests/test_stats.py`

**Interfaces:**
- Produces:
  - `read_stats(path: Path) -> list[dict]`
    - Reads CSV or XLSX (XLSX via `zipfile` + XML, still standard library only).
    - Headers are matched case-insensitively by alias:
      - views: `views|video views|plays|total plays|reach`
      - date: `date|post time|publish time|posted|published`
      - title: `title|caption|description|video title`
      - duration: `duration|video duration|length`
      - stayed: `stayed to watch|stayed_pct|average percentage viewed|completion rate`
      - file: `file|filename`
      - id: `id|video id|content`
    - Numbers accept `1,234`, `1.2K`, `3.4M`, `12%`.
  - `collect_folder(folder: Path, stats: list[dict]) -> tuple[list[Video], list[str]]`
    - Match by `file` column first. Otherwise match by date (the file's creation date or a date in its file name, ±1 day) plus duration (±1s).
    - Returns unmatched file names. It never guesses between two candidates.
